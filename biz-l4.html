① NEGOTIATION LANGUAGE · regatear · contraofertas · confianza
🤝 MAKE THE DEAL
RegatearCould we agree on…? · What if we…? · Would you consider…? · Is there any flexibility on…?
ContraofertasWould you be willing to meet us halfway? · We can agree to that if you… · If you can…, then we could…
ConfianzaI'm confident we can find a solution. · I believe this is a fair proposal. · This offers good value for both sides.
EstrategiaSé persuasivo pero profesional, y enfatiza el beneficio mutuo — "a win for both sides."
📘 CONDITIONALS FOR NEGOTIATION
1st conditional · B1 coreIf + present, will + base
"If you place a larger order, we will give a discount."
unless / as long as · B1+condición para avanzar
Unless we agree, we can't proceed. · We can start as long as the deposit is paid.
⭐ B2 STRETCH · 2nd & 3rd conditional
2nd (hipotético): If + past, would + base — "If we reduced the price, would you sign a long contract?"
3rd (pasado imaginario): If + past perfect, would have + participio — "If you had accepted the terms, we could have delivered last week."
⚠ Ojo: "If you had accepted… we could have delivered…" es 3rd conditional (pasado imaginario), NO 2nd. 2nd = presente/futuro poco probable; 3rd = un pasado que no ocurrió.

④ LISTENING · escucha las negociaciones
🎧 AUDIO 1 · PRICE NEGOTIATION

Un comprador y un proveedor negocian el precio. Fíjate en los condicionales y las condiciones.

⏱ 0:33🗣 Buyer + Supplier

01What does the buyer offer for a lower price?

02Under what condition does the supplier give 10%?

03Do they reach an agreement?

🎤Speaking: You are the buyer. Ask for a better price and offer something in return.

Buyer: If you lower the price by ten percent, we will place a larger order.

Supplier: I understand your request, but we can only offer five percent, unless you increase your order by twenty percent.

Buyer: What if we agree to a long-term contract? Would you consider the ten percent?

Supplier: If you commit to a one-year contract, we could offer you the ten percent discount.

Buyer: That works for us. I'm confident this is a fair deal for both sides.

🎧 AUDIO 2 · DELIVERY DEAL

Ahora negocian el plazo de entrega. Fíjate en la condición para adelantar la fecha.

⏱ 0:33🗣 Supplier + Client

01When can they deliver if the order is confirmed today?

02What does the client want instead?

03What condition does the supplier set for Wednesday?

Supplier: If you confirm the order today, we will deliver by Friday.

Client: I'm a little concerned about the timeline. What if we need it by Wednesday?

Supplier: We could deliver by Wednesday, but only if you agree to an express shipping fee.

Client: How much is the fee?

Supplier: It's a small extra charge. If you accept it, we can guarantee Wednesday.

Client: All right. If you guarantee Wednesday, we will proceed with the order.
